# Zephir

A simply notepad.

Requires:
- python3
- Gtk4

Note: the file com.zephyr.text.editor.png in icons
must be copied in /usr/share/icons/hicolor/48x48/apps/ .

Features:
- the most common ones;
- graphical configurator;
- single instance or multiple instance: in single instance, the current document can be detached from the main program, or a new instance can be launched by passing the argument "-t" or "--single-instance";
- printing;
- different font size choise for the view and the printer;
- etc.
